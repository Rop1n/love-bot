1)Заполните config. json: token, admin_id, client_id.

2)Если уже был db. sqlite3, удалите его для применения новой схемы.

3)Установка: pip install -r requirements.txt
Если aiohttp не ставится из за C++ Build Tools: set AIOHTTP_NO_EXTENSIONS=1 и повторите установку

4) Запуск: python main.py 
Если команда python не найдена, используйте ру.

5) Подарки выдаются вручную: админ получает заказ и использует кнопки «Исполнено» или «Отправить»

6) Импорт подарков: отправьте JSON файл через меню администратора «Импорт подарков»
